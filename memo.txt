function playGame() // ゲーム初期化用関数
  humanScore = 0, computerScore = 0
  ボタン表示用の要素controllerを作成
  テキスト表示用の要素displayを作成
  container要素を初期化
  controller要素にrock,paper,scissorsに対応するボタンを追加。
  それぞれのボタンにplayRound(ボタンに対応している手,getComputerChoice())を割り当てる。
  containerにcontrollerを追加
  containerにdisplayを追加
  function displayUpdate(str)
    文字列strを含むdivを結果表示用の要素displayに追加する。
  function checkFinishedGame()
    ゲームが終了していたら (どちらかが5点なら)
      displayUpdate(勝った方の勝利メッセージ)
      ボタン無効化
      playRound()を呼ぶリセットボタンをcontrollerに追加
  function playRound(humanChoice, computerChoice)
    人間が勝ちなら
      人間の得点を+1
      displayUpdate(勝利メッセージと得点表示)
    人間が負けなら
      コンピューターの特典を+1
      displayUpdate(敗北メッセージと得点表示)
    引き分けなら
      displayUpdate(引き分けメッセージと得点表示)
    checkFinishedGame()
  
playGame()
